This is my first more advanced project: using Java, C++, Assembly at the same time. Maybe the repository will look messy sometimes, but the result I want to reach will be awesome, so stay tuned ;D
I want to create something more useful than Minecraft plugins, websites, and systems. This is the Android app which provides control of electronical devices in my house. 
All them connected to a Raspberry Pi Pico 2W Board.
Devices included in my project:
- thermostat (soon)
- air sensor (currently BME280)
- led strip (currently WS2812B)
- electricity usage meter (soon)
- movement sensor (soon, i have amazing idea to use it)

Goal of this project is to learn Android development, creating microsystems using C++ and Assembly, writing drivers, and creating my own communication protocol for devices via wifi.
